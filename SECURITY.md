# Güvenlik

Repo private tutulmalıdır.

Dosyalara, issue'lara veya promptlara şunları koyma:

- personal access token
- API key veya şifre
- banka / ödeme bilgisi
- müşteri kişisel verisi
- sağlık veya aile bilgisi
- production secret
- imzalama anahtarı

AI ana dala commit atamaz, serbest shell komutu seçemez ve korunan Company OS yollarını
değiştiremez. Finans, hukuk, güvenlik ve diğer hassas departmanlarda kurucu onayı zorunludur.
