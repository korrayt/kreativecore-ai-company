# Brand System

## Core line

**Make It Simple. Make It Magic.**

## Voice

- clear
- capable
- calm
- creator-first
- technically credible
- never inflated

## Message order

1. User problem
2. Simple outcome
3. How it fits the creative workflow
4. Privacy and control
5. Proof
6. Call to action

## Avoid

- unsupported “best”, “first”, or “revolutionary” claims
- fake urgency
- invented performance figures
- promises not present in the current build
- complexity presented as sophistication
