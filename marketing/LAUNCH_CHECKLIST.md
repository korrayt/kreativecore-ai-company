# Launch Checklist

- [ ] Target user and problem are clear
- [ ] Product promise matches the build
- [ ] Screenshots show the current version
- [ ] Installation path works
- [ ] Pricing and license terms are approved
- [ ] Privacy statement matches actual data flow
- [ ] System requirements are verified
- [ ] Support and refund paths exist
- [ ] Release notes are ready
- [ ] Rollback or withdrawal path exists
- [ ] No secret or private data is published
