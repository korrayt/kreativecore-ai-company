# Company Workflow

## Intake

Work enters through:

- Product Proposal issue
- Task issue
- Bug issue
- Mobile Company Control
- A recorded company decision

## Triage

For each item determine:

- Which product or company function?
- What outcome is expected?
- Who owns it?
- What is the priority?
- What evidence will prove completion?
- Is sensitive data involved?

## Delivery flow

`PROPOSED → TRIAGED → ACTIVE → REVIEW → DONE`

Optional states:

`BLOCKED`, `PAUSED`, `CANCELLED`

## Pull request flow

1. Link the issue or decision.
2. Make a focused change.
3. Run validation.
4. Review with CodeRabbit and human judgment.
5. Resolve important feedback.
6. Merge only when the stated outcome is complete.

## Weekly review

Use **Actions → Mobile Company Control → weekly-review**.

The review issue must answer:

- What moved?
- What is blocked?
- What should stop?
- What are this week's three outcomes?
- Which risk needs attention?
