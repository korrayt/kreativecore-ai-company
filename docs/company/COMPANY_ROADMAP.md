# Company Roadmap

This roadmap uses outcomes rather than invented dates.

## Now — Foundation

- Complete Company OS and mobile GitHub control.
- Keep the repository free of secrets and generated dependencies.
- Verify the public Kreative Core Store structure.
- Establish one source of truth for each active product.
- Define release gates and decision records.

## Next — Product proof

- Validate Vision with a working end-to-end creator workflow.
- Validate CutMate's safe Premiere bridge and marker path.
- Benchmark Transcribe TR on real Turkish production material.
- Define licensing, support, pricing assumptions, and installation paths.

## Later — Distribution and scale

- Standardize product packaging and update delivery.
- Build unified account, license, and support architecture only after product proof.
- Expand automation around QA, releases, documentation, and customer support.
- Measure retention and workflow value before broad marketing spend.

## Roadmap rule

Each item needs an owner, status, next action, and evidence. Dates may be added only when they
are commitments rather than wishes.
