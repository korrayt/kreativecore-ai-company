# Organization

Kreative Core currently operates as a founder-led, agent-assisted company.

## Founder / Company Lead

Accountable for:

- vision and final prioritization
- product portfolio
- brand and public promises
- budget approval
- release approval
- sensitive decisions

Current owner: `@korrayt`

## Functional desks

| Desk | Responsibility | Default agent |
|---|---|---|
| Company | Strategy, priorities, decisions | Company Lead |
| Product | User problem, promise, scope, proof | Product Agent |
| Engineering | Architecture, implementation, reliability | Engineering Agent |
| Creative | Experience, visual language, simplicity | Creative Agent |
| Marketing | Positioning, launch, public communication | Marketing Agent |
| QA / Security / Release | Validation, risk, release gates | QA-Security-Release Agent |
| Finance | Budget assumptions and cost control | Founder + Finance templates |

## Assignment rule

Every active outcome must include:

- one owner,
- one status,
- one next action,
- one review date,
- one evidence link when available.

Agents may recommend and execute scoped work. Final approval for money, public claims,
security exceptions, product retirement, and production release remains with the founder.
