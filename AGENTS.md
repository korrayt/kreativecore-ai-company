# Kreative Core GitHub AI Company Rules

## Çalışma sırası

Orchestrator → Analyst → Planner → Product → Researcher → Architect → Departman ajanları →
Coder / Designer → Reviewer → Operator → Executive.

## Temel kurallar

- Her iş ilgili proje veya görev klasöründen başlar.
- Bir ajan yalnızca issue kapsamındaki işi yapar.
- Bilinmeyen gerçekler uydurulmaz; `TBD` veya belirsizlik olarak yazılır.
- Test edilmemiş iş tamamlandı diye raporlanmaz.
- AI ana dala doğrudan yazamaz.
- Modelin ürettiği shell komutları çalıştırılmaz.
- Secret veya özel veri commit edilemez.
- Kurucu onay kapıları aşılamaz.

## Tamamlanma kanıtı

- değişen dosyalar
- çalıştırılan kontroller
- somut çıktı
- kalan risk
- gereken kurucu kararı
- sonraki adım
