# Vision

## User

Editors working with large Premiere Pro projects and footage libraries.

## Problem

Finding useful shots and assembling a searchable visual understanding of footage consumes
creative time.

## Promise

Help editors find relevant shots using local visual analysis and creator-friendly search.

## Current stage

`VALIDATING`

## Verified public direction

- Premiere Pro workflow
- visual analysis and search
- privacy-oriented local processing
- lightweight and deeper analysis modes are part of the stated product direction

## Assumptions to verify

- installation size and hardware compatibility
- search quality on real production footage
- performance across long projects
- reliable sequence/stringout creation
- update and rollback process

## Next proof

A reproducible end-to-end demo:

1. install,
2. index footage,
3. search with natural language,
4. inspect results,
5. create a useful sequence,
6. repeat on another project.
